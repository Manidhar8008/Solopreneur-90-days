# Tools

Tools are deliberately small.

Start with:

```bash
python tools/solopreneur-pathfinder.py
```

The goal is not to build a giant platform inside GitHub.

The goal is to provide **small utilities that reduce the friction from knowledge → action**.

Planned tools:

- Pathfinder
- Revenue math
- Occupation audit generator
- Offer generator
- Customer pipeline tracker
- Personal context validator
- Graph visualizer
