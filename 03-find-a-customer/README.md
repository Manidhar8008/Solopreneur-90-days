# 03 — Find a Customer

A market is not an audience.

A customer is a person or organization that can:

1. feel the problem,
2. decide on a solution,
3. access money,
4. buy,
5. judge the outcome.

Learn acquisition before building complexity.

Explore:

- direct outreach
- local selling
- LinkedIn
- email
- communities
- referrals
- partnerships
- content
- existing networks

### Output

A list of real prospects and a repeatable outreach motion.
