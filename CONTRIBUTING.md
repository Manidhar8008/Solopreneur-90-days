# Contributing

This project is designed to improve through evidence.

## Good contributions

- Add an occupation pathway.
- Add a vertical opportunity map.
- Improve a customer acquisition playbook.
- Add a tool comparison with practical evidence.
- Add a real case study.
- Add exercises.
- Translate a module.
- Fix unclear instructions.

## Contribution standard

Prefer:

**specific → testable → reusable → evidence-based**

Avoid:

**generic → motivational → unverifiable**

## Pull request checklist

- [ ] Does this help someone reach a real customer or build a real capability?
- [ ] Is the claim supported by evidence or clearly labeled as a hypothesis?
- [ ] Is the content reusable?
- [ ] Did I avoid promises of guaranteed income, funding, or employment?
