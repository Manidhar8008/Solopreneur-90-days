# 01 — Know Yourself

Your current occupation is an asset inventory.

Map:

- skills
- domain knowledge
- customer exposure
- network
- available time
- money
- energy
- constraints
- credibility
- tools
- interests

### Output

Create your **Personal Solopreneur Map**.

Then identify the smallest capability gap that blocks you from creating customer value.
