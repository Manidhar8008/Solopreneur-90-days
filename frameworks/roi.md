# Customer ROI Framework

Customers buy outcomes, not technical enthusiasm.

## Basic model

```text
Customer ROI = Value created − Cost of solution
```

Where value can come from:

- revenue created;
- costs reduced;
- hours saved;
- errors prevented;
- speed increased;
- risk reduced;
- conversion improved;
- retention improved.

## The founder question

> “If this system works, what changes financially or operationally for the customer?”

If you cannot answer that, the offer is probably still too vague.
