# Vertical Selection Framework

Score each potential market from 1–5.

| Dimension | Question |
|---|---|
| Pain | Is the problem expensive or urgent? |
| Access | Can I reach buyers? |
| Expertise | Do I understand the workflow? |
| Willingness to pay | Does budget exist? |
| Delivery | Can I solve it with current + learnable skills? |
| Competition | Is there room for a focused offer? |
| Repeatability | Does the problem recur? |
| Leverage | Can technology improve the economics? |

A high score is not proof. It only determines **where to investigate first**.

## Vertical-first principle

Do not say:

> “I build AI solutions.”

Say:

> “I solve [specific workflow] for [specific buyer] using [specific mechanism].”
