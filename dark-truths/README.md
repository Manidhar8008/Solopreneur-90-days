# ☠️ Dark Truths of Solopreneurship

This directory exists to remove the fantasy layer.

The repository should teach ambition **and** the uncomfortable realities that ambition normally hides.

Every claim should be tagged:

- **EVIDENCE** — linked to a source.
- **PRACTICAL TRUTH** — operational lesson from repeated business practice.
- **INFERENCE** — conclusion derived from evidence and experience.

Read these before romanticizing entrepreneurship.
