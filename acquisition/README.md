# Customer Acquisition

Acquisition is a system, not a single tactic.

## Channel map

- LinkedIn
- Cold email
- WhatsApp
- Reddit / communities
- Local outreach
- Referrals
- Partnerships
- Content
- Search
- Events
- Existing employer network where permitted and ethical

## Acquisition loop

```text
Target list
 ↓
Message
 ↓
Conversation
 ↓
Qualification
 ↓
Demo / proposal
 ↓
Close
 ↓
Delivery
 ↓
Proof
 ↓
Referral / case study
 ↓
More prospects
```

## Rule

Do not optimize vanity metrics before optimizing **qualified conversations and customer outcomes**.
