# 07 — Build Your System

After solving the same problem repeatedly, turn the work into a system.

```text
Repeated work
    ↓
Checklist
    ↓
Template
    ↓
SOP
    ↓
Automation
    ↓
Delegation
    ↓
Productized service
```

Automate only after you understand the workflow manually.

### Output

A repeatable delivery system that reduces your dependence on memory.
