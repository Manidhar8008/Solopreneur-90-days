# Community

The project becomes stronger when contributors add evidence.

Good contributions include:

- occupation pathways;
- local-market examples;
- vertical playbooks;
- customer interview patterns;
- case studies;
- translations;
- technology decision guides;
- tool improvements.

Low-value contributions include generic motivational quotes or unsourced claims.

## Contribution quality

**Evidence > opinion.  
Useful template > long essay.  
Specific market example > generic advice.**
