# 🤖 Bring Your Own AI

This repository is designed to work with the learner's own AI agent.

The repository provides:

1. **Knowledge** — frameworks, modules, tools, case studies.
2. **Context schema** — the learner's personal state.
3. **Agent instructions** — rules for how an AI should use the material.
4. **Graph schema** — relationships between the learner, skills, markets, problems, offers, customers, and systems.

The AI should never replace evidence from real customers.

It should help the learner:

- understand the curriculum;
- personalize the roadmap;
- identify missing capabilities;
- choose the next experiment;
- summarize evidence;
- maintain progress;
- challenge assumptions.

## Provider-neutral

This is designed for:

- ChatGPT
- Claude
- Gemini
- OpenAI API
- local models
- custom agents

The repository itself should not require a specific AI vendor.
